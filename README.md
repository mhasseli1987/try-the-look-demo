# Try the Look — Fashion Store Template

قالب فروشگاهی «Try the Look.» با HTML، CSS و جاوااسکریپت خالص (بدون هیچ فریم‌ورک یا کتابخانه). یک ویترین رانوی تعاملی برای فروشگاه‌های پوشاک: چرخ‌فلک سه‌بعدی مدل‌ها، پین‌های محصول روی مدل، انتخاب سایز، سبد استایل محلی و پنل «In this look».

## ویژگی‌ها

- **چرخ‌فلک سه‌بعدی حلقه‌ای** روی دسکتاپ و **صف مورب کلاسیک** روی موبایل
- **پخش خودکار** با نوار پیشرفت، درگ ماوس، سوایپ لمسی، کلیدهای جهت‌دار و مومنتوم
- **کرسر سفارشی** با حالت‌های Drag / View
- **پاپ‌آپ View look** با انیمیشن FLIP و پین‌های شماره‌دار محصول
- **پنل In this look** با انتخاب سایز و افزودن تک‌پوش
- **Add full look to bag** با پیام «سایز را انتخاب کنید»
- **سبد استایل محلی** در `localStorage` با دیالوگ، شمارنده و دانلود لیست (بدون پرداخت)
- **دسترس‌پذیری کامل:** live region، aria-current، فوکوس visible و پشتیبانی `prefers-reduced-motion`
- بدون وابستگی خارجی؛ فونت Inter به‌صورت base64 داخل HTML

## فایل‌ها

| فایل | توضیح |
|---|---|
| `index.html` | نسخه نهایی و مستقل سایت (همین فایل را باز کنید یا روی هاست بگذارید) |
| `src/styles.css` | استایل کامل: توکن‌ها، چیدمان، انیمیشن‌ها و مدیا کوئری‌ها |
| `src/runway.js` | تعریف `<runway-section>` با `customElements.define` و منطق سبد خرید |
| `build.js` | سازنده `index.html` از روی `src/` و `catalog.json` |
| `catalog.json` | داده محصولات، واریانت‌ها و لوک‌ها |
| `assets/` | تصاویر مدل‌ها و محصولات (فایل‌های محلی) + فونت |

## اجرا و استقرار

فایل `index.html` را در کنار پوشه `assets/` باز کنید؛ به سرور یا build نیاز نیست. برای استقرار روی هر هاست استاتیک (Netlify، Vercel، Render، GitHub Pages و…) کل پوشه را آپلود کنید.

## شخصی‌سازی

1. **محصولات:** در `catalog.json` هر آیتم باید `id`, `name`, `price`, `image`, `sizes`, `variants[{id,a,o}]` و `url` داشته باشد. `url` را روی صفحه محصول خودتان تنظیم کنید (الان `#` است).
2. **لوک‌ها:** ترتیب محصولات هر لوک از `looks[].products` می‌آید؛ نام و توضیح هر لوک هم همان‌جا.
3. **پین‌ها و تگ‌ها:** در `build.js` داخل `PINS` و `TAGS`.
4. **رنگ‌ها و اندازه‌ها:** توکن‌های inline روی `<runway-section>` و ابتدای `src/styles.css`.
5. بعد از هر تغییر `node build.js` را اجرا کنید تا `index.html` دوباره ساخته شود.

## نکته‌ها

- قیمت باندل به‌صورت خودکار از جمع محصولات هر لوک محاسبه می‌شود و تخفیف ۱۰٪ فقط نمایشی است؛ سبد هر قلم را با قیمت کامل جمع می‌زند.
- سبد خرید محلی است و هیچ پرداخت یا سفارشی ثبت نمی‌کند؛ برای اتصال به درگاه واقعی، دکمه‌های افزودن را به بک‌اند خودتان وصل کنید.
- تصاویر مدل‌ها و محصولات فقط دمو هستند؛ پیش از استفاده تبلیغاتی، مجوزهای تصویری را بررسی کنید.
